# Contributing

Thanks for taking an interest in InkReader.

Please keep reports reproducible and avoid uploading copyrighted novels,
private device identifiers, NFC captures containing personal data, or full
logs without checking them first.

Useful issue details:

- Phone model and Android version
- Panel type A0 or A1 and its physical markings
- Whether Shizuku or root is used
- Exact app version from the APK
- Steps to reproduce
- Relevant sanitized logs

Protocol or hardware compatibility changes should preserve the upstream
noncommercial licensing and attribution requirements.
